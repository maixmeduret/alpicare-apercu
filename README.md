# FLYCARE — aperçu

Aperçu statique du site FLYCARE et de la maquette ALPICARE, destiné à être montré
de la main à la main. Les pages portent `noindex, nofollow` et le `robots.txt`
interdit toute exploration : rien n'est référencé par les moteurs de recherche.

- `/` — le site FLYCARE, ses trois pages
- `/maquette/` — la maquette ALPICARE, direction visuelle retenue

L'assistant de questions-réponses est retiré de cet aperçu : il a besoin du
serveur local pour fonctionner. Le code complet vit dans le dépôt privé `flycare`.

Maquette de travail. Les tarifs restent à valider auprès d'Alptis.
